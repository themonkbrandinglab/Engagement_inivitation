# Dawn & Lotus Invitation

Create a **premium, cinematic, modern engagement invitation website** for **Aruna & Aravind**.

The website must feel **luxurious, elegant, romantic, minimal, and visually stunning**. The first-time visitor should immediately get a **“WOW” feeling**, while still keeping the website neat, clean, readable, and tasteful.

Do NOT create a story/timeline section. This is a direct engagement invitation website focused on the couple, event details, countdown, location, calendar integration, RSVP, and sharing.

---

# 1. CORE THEME — DAWN & LOTUS

Use a sophisticated **“Dawn & Lotus”** visual theme throughout the entire website.

The design should combine:

- Soft dawn/sunrise atmosphere

- Elegant lotus flowers

- Subtle Indian aesthetic

- Warm golden sunlight

- Soft blush pink

- Ivory/cream

- Champagne gold

- Very subtle peach tones

- Occasional deep rose accents

The lotus should feel **premium and realistic**, not cartoonish.

Use the theme consistently across:

- Backgrounds

- Decorative elements

- Images

- Buttons

- Cards

- Typography

- Animations

- Transitions

- Loading/entry experience

Do not overuse lotus elements. Keep them subtle and sophisticated.

---

# 2. OVERALL DESIGN PHILOSOPHY

The website should feel like a combination of:

**Luxury wedding invitation + cinematic landing page + premium editorial design**

Prioritize:

- Clean layouts

- Large typography

- Generous whitespace

- Elegant composition

- Strong visual hierarchy

- High-quality imagery

- Smooth transitions

- Subtle motion

- Premium micro-interactions

- Mobile-first responsiveness

Avoid:

- Clutter

- Too many cards

- Excessive text

- Cheap-looking gradients

- Excessive animations

- Cartoon graphics

- Generic template appearance

- Overly bright colors

- Unnecessary sections

Every element should have a purpose.

---

# 3. OPENING / ENTRY SCREEN

Create a full-screen cinematic opening experience.

Content:

✦

YOU'RE INVITED

ARUNA

&

ARAVIND

TO THEIR ENGAGEMENT

21 • 10 • 2026

↓

ENTER

The opening should feel like entering a luxury invitation.

Animation sequence:

1. Start with a soft dawn-inspired background.

2. Very subtle golden light slowly appears.

3. Lotus petals or extremely subtle floral elements gently move.

4. The small ✦ symbol fades in.

5. “YOU'RE INVITED” appears.

6. ARUNA and ARAVIND reveal elegantly.

7. The date fades in.

8. ENTER button appears last.

The animation should be slow, sophisticated and cinematic.

Do not make the opening flashy.

The ENTER button should have a subtle hover effect and elegant ripple/glow interaction.

When ENTER is clicked, transition smoothly into the main website with a cinematic fade/zoom transition.

---

After entering:

ARUNA × ARAVIND

Use the couple's names as the main visual focus.

The image should integrate naturally with the Dawn & Lotus theme.

Use:

- Soft floral framing

- Golden light

- Subtle lotus elements

- Elegant image masking

- Soft depth

- Gentle parallax movement

Do NOT make the image look like a random stock photo.

---

# 11. IMAGE HANDLING

Use high-quality images that perfectly match the **Dawn & Lotus** theme.

If external images are required, intelligently select appropriate royalty-free/usable images from reliable sources.

If AI-generated imagery is available, generate images specifically matching this visual direction.

Images should feel:

- Indian

- Elegant

- Romantic

- Natural

- Premium

- Dawn-inspired

- Lotus-inspired

- Cinematic

Avoid generic western wedding imagery that doesn't fit the theme.

Avoid mismatched colors.

Every image should look like it belongs to the same visual world.

Use appropriate image cropping and responsive object positioning so images never look stretched, distorted, or awkward on mobile.

Use lazy loading for images where appropriate.

---

# 12. ANIMATIONS & MOTION

Animations are important, but they must remain elegant.

Use:

- Smooth page transitions

- Fade-in animations

- Gentle slide-up reveals

- Scroll-triggered animations

- Subtle parallax

- Floating lotus petals

- Slow background movement

- Soft light movement

- Elegant text reveals

- Button hover animations

- Image reveal animations

- Micro-interactions

- Smooth modal transitions

Use animation libraries such as GSAP / Framer Motion where appropriate.

Animations should feel:

**cinematic + luxurious + smooth**

NOT:

**fast + flashy + distracting**

Respect `prefers-reduced-motion`.

---

# 13. SMOOTH SCROLLING

Implement premium smooth scrolling.

Scrolling between sections should feel fluid and natural.

Use subtle scroll-based motion.

Do not make scrolling difficult or overly slow.

Mobile scrolling must remain responsive and natural.

# 17. BACKGROUND DETAILS

Create subtle layered backgrounds using:

- Dawn gradient

- Soft sunlight

- Fine grain texture

- Extremely subtle botanical silhouettes

- Lotus petals

- Light particles

- Soft blur

- Gentle atmospheric depth

Keep backgrounds subtle so text remains readable.

---

# 18. RESPONSIVE DESIGN

The website must be designed mobile-first.

Most guests will open the invitation from WhatsApp on their phones.

Optimize specifically for:

- iPhone

- Android phones

- Tablets

- Desktop

On mobile:

- Typography must remain readable.

- Buttons must be thumb-friendly.

- Images must crop beautifully.

- Animations must remain smooth.

- No horizontal scrolling.

- No layout breaking.

- Calendar and Maps buttons must be easy to tap.

---

# 19. PERFORMANCE

Despite the cinematic visuals, the website must remain fast.

Implement:

- Lazy-loaded images

- Optimized image formats

- Responsive image sizes

- Code splitting where useful

- Efficient animations

- Avoid unnecessary JavaScript

- Avoid excessive DOM elements

- Optimize fonts

- Prevent layout shifts

The website should feel premium without becoming slow.

---

# 20. FINAL SECTION

End with:

ARUNA & ARAVIND

21 • 10 • 2026

✦

WITH LOVE

# 21. IMPORTANT DESIGN RULE

The final website must NOT look like a generic AI-generated wedding template.

It should feel like a **custom-designed luxury engagement invitation**.

The first 3–5 seconds should create a strong:

**“WOW, this is beautiful.”**

reaction.

Use visual storytelling through **design, imagery, light, motion and typography**, but DO NOT create a story/timeline section.

The website should communicate:

**Elegant. Romantic. Premium. Indian. Modern. Cinematic.**

Keep everything **neat, clean and intentional**.

Do not sacrifice usability for visual effects.

Build the complete responsive website with production-quality UI, polished animations, working countdown, working Google Maps button, working Add to Calendar functionality, working .ics generation, and responsive mobile experience.
